# MDReader 示例文档

一个**轻量**的 Markdown 阅读器，支持 *斜体*、`行内代码` 和 [链接](https://example.com)。

## 功能列表

- 实时预览，文件保存后自动刷新
- 目录导航 (TOC)
  - 支持多级标题
- [x] Finder 缩略图
- [ ] Windows 版本

> 提示：按 ⌘F 可以在文档中搜索。

```swift
let reader = MDReader()
reader.open("README.md")
```

|------|------|------|
| macOS | ✅ | 原生 |
